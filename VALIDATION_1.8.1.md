# EdgeControl 1.8.1 validation

## Scope

The capsule width regression is confirmed against the 1.7.7 source: 144 pt became 180 pt in 1.8.0. This patch restores normal/error widths to 144/212 pt while retaining a 40 pt height. The notch content strip becomes 24 pt, and width follows the reported cutout plus 8 pt total, subject to the minimum content width. Text remains below the physical cutout.

Existing geometry tests now assert the restored capsule dimensions and slim notch dimensions across scaled displays. Native light/dark UI snapshots are generated by CI. The 144-test suite also retains migration, display selection, haptics and input coverage. Repository invariants, shell syntax and diff whitespace checks pass locally; full macOS test/build results are recorded in the PR after CI completes.

## Alcove investigation

Installed Alcove 1.7.9 has brightness and volume HUDs enabled. Off only suppresses EdgeControl's own panel; there is no third-party dispatch in the application. No supported public HUD trigger contract was found in the reviewed official site/release tracker. The presence of an alcove URL scheme is not evidence of a volume/brightness HUD API. Do not claim integration works, or infer that any particular event is the only trigger.

References: https://tryalcove.com/ and https://github.com/waydabber/BetterDisplay/issues/5103 (maintainer describes notification-based brightness observation and the need for receiver-side integration changes). Alcove's own tracker also records third-party brightness HUD issues: https://github.com/henrikruscon/alcove-releases/issues/78.

This patch corrects the misleading External label and preserves hardware control. It does not solve Alcove HUD activation. Synthetic media keys or guessed private notification payloads are not introduced. Check real edge gestures on the installed Alcove version before relying on external visual feedback.

## Physical checks still needed

Compare capsule and notch on the user's display, in full screen and with external displays. Validate aesthetic preference and the unchanged haptic behavior with real gestures. Geometry tests and native rendered screenshots cannot certify every hardware combination.
