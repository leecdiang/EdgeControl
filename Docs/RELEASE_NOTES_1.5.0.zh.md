# EdgeControl 1.5.0

新增三档触觉反馈，并将精简 HUD 改为更凝实的真实磨砂效果。

## 新功能

- 触觉反馈新增轻、标准、强三档。升级用户默认使用标准档，原有触觉反馈开关保持不变。
- 轻档使用每 4% 一次的轻微 alignment 反馈；标准档保留原有每 2% 一次的 alignment 手感；强档使用每 2% 一次、体感更强的公开 AppKit generic 反馈。
- 手势激活时锁定触觉档位，途中修改设置不会改变本次滑动的触感。
- 未验证的私有触控板执行器继续保持禁用；三档均只使用 `NSHapticFeedbackManager`，无需额外权限。

## HUD

- 正常 HUD 从 148×42 缩小到 144×40，错误状态从 220×42 缩小到 212×40。
- macOS 13+ 改用严格裁切在胶囊内的 `NSVisualEffectView`，提供真实 `.hudWindow` 背景模糊。
- 叠加 52% 动态雾面遮罩、稍强的色调、细高光描边与重新调整的阴影，降低通透感并保留磨砂层次。
- AppKit 图层与 SwiftUI 胶囊进行双重裁切，避免早期 Liquid Glass 方案在浅色背景上出现矩形底板。
- “降低透明度”仍使用完全不透明的系统背景；“减少动态效果”仍会移除缩放动画。

## 测试与验证

- 新增 3 项回归，覆盖触觉档位持久化与异常值回退、标准档兼容、轻档间隔及强档模式选择。源码测试总数增至 55 项。
- 源码侧仓库检查与 Shell 检查已通过；发布前仍须在 macOS 完成 Xcode 构建/测试及触觉、HUD 真机检查。
- AppKit 只提供系统反馈模式，没有数字振幅。不同硬件的体感排序可能不同，须分别验证内置与外接 Force Touch 触控板。
