# EdgeControl 1.2.1

这是一次聚焦稳定性的修复版本，解决“仅从下半部分开始”模式在手势激活时发生音量 / 亮度突变的问题。

## 修复

- 下半部分模式不再把手指滑入时的绝对高度直接写成音量或亮度；从接近中线的位置滑入也不会再瞬间跳到接近 100%。
- 所有通过准入的手势现在统一以激活瞬间读取到的系统数值为锚点，只应用激活后的累计纵向位移；激活本身不会改变数值。
- 仓库验证脚本改为接受后续新增测试，同时在测试数低于 32 项基线时失败，修复原先仍写死 29 项而导致 CI 提前中止的问题。

## 说明调整

- “仅从下半部分开始”现在明确表示准入过滤：出生在归一化触控板中线以上的触点直接拒绝；通过准入后的调节方式与普通模式一致，均为相对调节。
- 设置页和中英文 README 已同步更新，准确说明无跳变行为。

## 验证

- 仓库静态验证、全部 32 项单元测试和干净的 Release 构建均通过。
- 开启下半部分起始过滤，从低、中、高多个纵向位置滑入：第一帧保持原值，激活后的上下移动保持连续。
- 精简 HUD、2% 触感、Release 日志防护、DMG 安装流程和 SHA-256 均已复查。
