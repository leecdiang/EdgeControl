# EdgeControl 1.2.0

边缘手势加了防误触，HUD 默认回归系统风，触控板控制可以只在下半部分进行。

## 新功能

- 仅下半部分模式：边缘控制只响应触控板下半部分，中线对应 100%，最底部对应 0%。从中线以上开始的触点直接拒绝，能减少手掌和误触。位置按触控板归一化，不同机型通用。
- 彩色 HUD 改为可选项。默认是无色的系统风格，在设置里打开 "Colorful HUD" 可恢复原来的音量/亮度配色。

## 变更

- 手势准入更严格：450ms 进入超时、激活前 3% 走廊、激活后 8% 走廊、方向一致性 0.80。手掌晃动在成为控制会话前就会被拒绝。
- 触感反馈从每 5% 一次加密到每 2% 一次，冷却时间缩短到 30ms。
- HUD 改为单行胶囊，正常 148x42、错误 220x42，使用单一常驻视图。macOS 26 用原生 Liquid Glass 效果，旧系统回退到材质背景，并支持"减少动态效果"和"降低透明度"。
- 外接显示器 DDC 设置现在会持久保存。
- 设置窗口按内容自适应大小，不再固定 520x420。
- C 桥接层的原始触控日志在 Release 构建中不参与编译。
- DMG 打包脚本结束时能可靠卸载临时挂载。

## 修复

- 设置里 "Touch input" 行与上方各行未对齐的问题。
