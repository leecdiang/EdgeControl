# EdgeControl 1.4.0

新增彼此独立的调节速度与隐私型误触保护。

## 新功能

- 调节速度独立分为精细（`0.50×`）、标准（`0.70×`）、快速（`0.95×`），只影响激活后的数值增益。
- 误触保护独立分为强、标准、轻：组合 600/350/200ms 打字窗口，以及左侧 0.6%/0.8%/1.0%、右侧 1.2%/1.5%/1.9% 的触点出生范围。
- 旧版连续灵敏度自动迁移到最接近的调节速度档。
- EdgeControl 只查询距离最近一次 Quartz 按键按下事件经过了多久；不会安装键盘事件监听器、读取具体按键或保存键盘活动。
- 最近打字可拒绝空闲或尚未激活的边缘触点，且拒绝状态锁存到所有手指抬起，避免手掌停留到计时结束后突然激活。
- 已经进入 Active 的音量或亮度手势不会被打字保护中断。
- 手势激活时锁定调节速度；有手指按下时修改准入设置，该触点会一直丢弃到抬手。
- “仅从下半部分开始”仍是独立的可选过滤，不再是唯一的强防误触方案。

## 同时包含的可靠性修复

- 包含 1.3.1 的内屏亮度路由修复：内屏枚举瞬时失败时，仅使用内屏的 Mac 不再被隐式路由到 External DDC。
- 亮度手势锁定激活时后端；显示器变化时只安全结束正在进行的亮度会话，再刷新后端。

## 测试

- 新增 12 项回归：打字拒绝与锁存、Active 连续性、档位时间与左右边缘范围、硬规则不变性、速度增益、旧值迁移、异常偏好及 Quartz 无效时间处理。
- 当前源码共包含 52 项 XCTest。

## 发布前验证

- 在 macOS 上运行全部 52 项测试，并完成 Release / Universal 2 构建。
- 真机验证全部三档调节速度与误触保护，包括 600ms、350ms、200ms 时间边界和左右不对称出生范围。
- 使用干净 macOS 账户确认时间查询不会触发辅助功能或输入监控权限提示。
- 重跑 1.3.1 的无外屏亮度矩阵。外接 Magic Trackpad、外接 DDC、Intel 真机、Developer ID 签名与公证仍未验证。
