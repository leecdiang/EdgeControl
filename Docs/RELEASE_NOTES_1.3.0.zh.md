# EdgeControl 1.3.0

新增实验性的外接 Magic Trackpad 输入与明确的设备选择；“自动”继续保留现有默认设备路径。

## 新功能

- 新增触控板来源选择：自动、内置触控板、外接 Magic Trackpad。
- “自动”完整保留已经验证过的 1.2.x `MTDeviceCreateDefault` 行为。
- 显式选择会动态枚举设备，并把当前来源显示为 Built-in、External；无法分类时显示 Running。
- 连接或断开设备后可点击“Rescan Trackpads”重新打开选定来源，选择会跨启动持久保存。

## 安全性

- 外接候选必须同时满足“非内置”和“横向触控面”，这项安全过滤的设计目标是排除纵向的 Magic Mouse 触控面，仍需真机确认。
- 枚举 / 分类符号缺失或指定设备不存在时安全失败并显示错误；“自动”路径仍然可用。
- 活跃触点生命周期加入 750ms 回调静默看门狗：候选或 Active 因蓝牙断开而收不到结束帧时会重置，并在需要时恢复光标与触觉状态；恢复的旧触点帧会丢弃到抬起或重扫为止。
- 1.2.1 的无跳变相对映射，以及 450ms、走廊、方向一致性和多指防护全部保持不变。

## 测试与文档

- 测试增加到 35 项，新增设备选择持久化 / 异常值回退和外接触控面几何过滤测试。
- 中英文 README、架构、验证、构建状态和 OpenClaw 交接文档均已同步实验性支持范围及真机测试矩阵。

## 验证状态

- 本机已验证：35/35 测试、Release 与 Universal 2 构建、内置触控板手势（450ms 准入、走廊、方向一致性、多指锁存、下半部分过滤、无跳变映射）、HUD、音量、亮度与光标恢复。
- 外接 Magic Trackpad / Magic Mouse 硬件矩阵尚未实测：发布时无外接设备可用。安全过滤（非内置 + 横向触控面）与断连看门狗已通过单元测试，但仍需真机确认。外接设备上的触觉反馈位置不受 AppKit 公共后端保证，需单独验证。
