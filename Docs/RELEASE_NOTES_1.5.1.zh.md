# EdgeControl 1.5.1

本版本集中提升边缘手势、强档触觉反馈与多显示器 DDC 的可靠性。

## 修复

- 过零取消逻辑固定使用手势激活方向，关闭缓慢穿过死区后继续反向调节的绕过路径。
- 强档第二次脉冲改为由手势生命周期管理，结束或唤醒复位时立即取消。
- 外接 DDC 写入复用初始读取成功的连接，避免多显示器读写对象不一致。
- 设置中将触觉总开关与强度档位放在同一区域。
- Bundle 构建号改为读取 `CURRENT_PROJECT_VERSION`（build 2）。

## 测试与验证

- 新增 4 项回归，源码测试总数增至 60 项 XCTest。
- 源码侧仓库验证已通过。
- 发布前请在 macOS 执行 `OPENCLAW_VALIDATE_1.5.1.md`；触感和真实 DDC 硬件行为不能仅凭合成测试确认。
