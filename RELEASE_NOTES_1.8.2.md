# EdgeControl 1.8.2

- Keeps HUD previews synchronized with the selected Capsule, Notch or Off mode, removing the separate cached preview state.
- Adds a subtle neutral scrim to the menu panel for steadier contrast.
- Restores the settings window's frosted backdrop and adds native Liquid Glass navigation and preview buttons on macOS 26+.
- Simplifies settings labels and moves secondary explanations into tooltips and disclosure controls. Off still clearly states it does not activate Alcove.
- Preserves macOS 13–15 fallbacks, Reduce Transparency, compact HUD dimensions and all existing gesture/haptic behavior.
